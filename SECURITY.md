# Security policy

Please do not open a public issue for a suspected security vulnerability. Contact the maintainer at
`notabdelrahmanelsayed@gmail.com`, as declared in `paymob_integration/hooks.py`.

Include a reproducible description, affected version, security impact, and safe reproduction details.
Do not include live credentials, card data, HMAC secrets, customer data, or raw production payloads.
Use fake values and redact logs before sending them.

Reports will be acknowledged when received and handled through coordinated disclosure. We will work
with the reporter on a fix and disclosure date, but this alpha does not promise a response or fix
timeline.
